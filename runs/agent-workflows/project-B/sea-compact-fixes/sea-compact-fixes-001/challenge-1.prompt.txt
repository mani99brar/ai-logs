It moors as soon as it is at or below `dockMaxSpeed`, even if it is still sliding. Everything else about docking stays as it is, including casting off on reversing throttle. Simulation unit tests sweep approach headings (every 8 heading units around the berth's open sides), start speeds (0, half and full) and lateral offsets across the reach. Today that resets the moored throttle latch, so when the player's unchanged held keys resume, ahead is read as a new press and the ship casts off. A lapse to neutral must leave a moored ship's latch untouched. Only real input from the client can release or reverse it. An `inputGate` or integration test drives this with a headless client: dock with ahead and E held, stop sending input for 400 ms, resume with ahead still held, and the ship is still moored. It casts off once the client releases and presses ahead again (or reverses).
8. `docs/architecture.md` describes the docking rule (hold E near a dock to brake and moor) in its sailing section, within today's length.

## Decisions

- sea-compact-001's candidate `8328920` passed every check, and its general reviewer approved it. The coverage reviewer blocked it on two P1s: an untested map-size ceiling, and a dock-reach assertion that can never fail. Because the general reviewer approved the whole feature, this follow-up builds on the candidate itself (branch `sea-compact/base`), without restoring a snapshot. The new reviewers see only the fixes.
- The two P1s plus four P2s (real key events for taps, clearing the tap on blur, the rescaled visibility bound, a sketch drift test) are in scope.
- Two docking problems a player would feel are in scope, because the game should feel good, and this feature owns the same files.
  - Holding E within reach of a dock with a clear path brakes the ship, overriding ahead, and moors it once slow enough. Arriving at an angle no longer slides past the dock.
  - A server lapse to neutral after a 250 ms input stall no longer resets the moored latch, so a stall can't cast a ship off.
- The handling baseline becomes a named literal (today's pre-compact tuning), so the ±25 % handling tests can fail.

## Assumptions

- Hold-E braking applies only within the dock reach, with a clear hull path to a berth. Elsewhere, E does nothing to sailing.
- The existing docking rules stay as they are: the reach, `dockMaxSpeed`, and casting off on reversing throttle.

## Deferred

- A verifier-side `--repeat-each` check (it would be a policy change); the worker still reports its local repeat count.
- A test for the printed `map:build` report lines: maps.test.ts already asserts the report's values.
