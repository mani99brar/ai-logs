## Decisions

- This is a follow-up feature on top of skeleton-001's candidate (snapshot `50b14b3`, branch `skeleton/candidate-001`), not a new run of `skeleton`: the lane starts from the reviewed code and changes only what `game-task.md` lists. Reviewers review this diff; the skeleton's own requirements in `features/skeleton/` still apply.
- Scope is findings 1–11 of `game-task.md`: both P1s, the P2s that are cheap to close (3, 4, 5, 6, 7, 8) and the operator's code-review findings 10 and 11. Finding 9 is already fixed in this base. The general reviewer's P2 about `allocateCode` exhausting its 16 attempts is deferred.
- Private-match admission has three layers, because Colyseus reserves a seat before any room-level check runs. Checking in the room alone would still let code-less HTTP joins reserve seats and fill a match. The design challenge of run skeleton-fixes-001 (attempt 1) proposed this design.
  - (a) The static `onAuth` (`authorizeEntry`) refuses, before any seat is reserved, a request with neither a well-formed `code` nor a `createToken`, and one with both (400). It keeps its existing checks: protocol version (426), unknown code through `matchMaker.query` (404, "No match with that code"), and full match (409).
  - (b) The room is registered with `filterBy(["code", "createToken"])`. A `create` carries a one-time random `createToken` of at least 128 bits, generated with the platform's crypto API outside the pure packages. Colyseus copies `filterBy` fields from the create options into the listing's metadata, so `onCreate` must replace the metadata (`setMatchmaking`) so it never keeps the token. A request carrying a token then matches no existing listing: `join` fails, and `joinOrCreate` can only create.
  - (c) The room's `onJoin` (or instance `onAuth`) is the backstop, which also covers `joinById`. It admits exactly one seat carrying the token stored in `onCreate` (the creator's); every other seat must carry `code` equal to `this.state.code`.
  - What remains: someone who already knows a roomId (a current or former member) can reserve seats through `joinById` until they expire. `docs/architecture.md` records this.
- The join options change, so `PROTOCOL_VERSION` goes from 1 to 2; tests and the HUD read the constant, not a literal.
- The build output is proven inside the existing `build` check: `npm run build` finishes with a smoke script under `scripts/` that runs the built server on a free port, creates a match through `@colyseus/sdk` and stops it. The policy stays unchanged, and `build` runs before `browser` in the verifier's order.
- The generic matchmaker failure (`MATCHMAKE_INVALID_CRITERIA`) is shown as "That match is full or no longer exists"; "No match with that code" is kept for the server's own 404 refusal.

- Refusal messages stay under 100 bytes. A refusal from the room arrives after the WebSocket opens and may travel as a close reason, which WebSocket caps at 123 bytes. Integration tests assert the exact text.
- The build smoke script runs the server with `PORT=0` and reads the port from its "listening" line. It limits every wait and kills the server on every path, so a failure shows its real error instead of the build check's 600 s timeout, and no orphan disturbs the browser check.

## Assumptions

- In Colyseus 0.18.16, a seat reservation returns only `name`, `sessionId`, `roomId` and `processId` (`buildSeatReservation` in `@colyseus/core`), not listing metadata. A reservation therefore does not reveal the code; the risk the layers close is seat squatting.
- The room's `onJoin(client, options)` or instance `onAuth` can refuse a seat by throwing, and the client receives the error's message.
- Frame tags keep their current meaning in this feature: checked against the 30-frame future window, then applied from the next step. Only the documentation changes.
- `tests/reporters/testSummary.ts` stays registered in `vitest.config.ts`; new test files need nothing extra to be counted.
- The lane may add test files anywhere under its owned paths and may adjust existing tests only where a finding says they are wrong (finding 10, and literals of the protocol version).

## Deferred

- Frame-accurate input application, client prediction and reconciliation: the combat spike.
- Replacing the `colyseus` meta-package with `@colyseus/core`, `@colyseus/ws-transport` and `@colyseus/schema` (it would drop `uWebSockets.js` fetched from GitHub during `npm ci`).
