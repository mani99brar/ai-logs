## Acceptance

Each item names the test that proves it.

1. **Per-player request ids.** Purchases are keyed by (playerId, requestId), so one player's id can never refuse or reveal another's purchase. Scripted test: two players use the same id and both succeed. Each one's retry replays their own result.
2. **Refusals replay too.** Every purchase result is recorded, refusals included. A retry of the same (playerId, requestId) returns the original result, refusal or success, with the very same state, even if it would succeed now. Scripted test: a purchase refused for short gold, retried after a grant, still returns `insufficient-gold`, and a new id then succeeds. Update `docs/objectives.md`.
3. **The minting invariant.** The ledger records each player's starting purse (from `addPlayer`) and every grant. `checkLedger` asserts that `goldIssued` equals the sum of purses plus the sum of grants, and that `balances + goldSpent = goldIssued`. `addPlayer` accepts only the rules' `startingGold` (a caller-chosen purse is refused), unless a documented test-only option is used. Scripted test: a state with `goldIssued` and a balance both raised outside `grantGold` fails `checkLedger`.
4. **Bounded grant keys.**
   - A `ruin` grant's key must be one of the ledger's islands (known from its sources).
   - A `supply-cache` grant's key must be one of the supply-cache ids given at ledger creation (a new optional `supplyCaches` list in `createLedger`; none means no supply-cache grants).
   - Unknown keys are refused as `unknown-source`.
   - Scripted tests for both, including a fresh unknown key per call failing every time.
5. **Sharper checks.**
   - The property checker asserts, per step, that a successful `useTonic` found no active tonic for that player in the prior state, so stacking would fail.
   - Scripted tests refuse purchases and `useTonic` in the duel's `choosing` window as well as `fighting`.
6. `npm ci` then `npm run typecheck`, `npm run test:unit`, `npm run test:integration` and `npm run build` pass from a clean checkout.
