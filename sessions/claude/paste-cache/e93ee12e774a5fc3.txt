A coding outcome brief
Goal: [observable user or system result].
Context: [repository, relevant paths, existing behavior, reproducer or reference].
Constraints: [compatibility, architecture, scope and actions requiring my decision].
Acceptance: [behavior checks, edge cases, expected artifact and evidence].
Process: inspect what matters; ask about high-impact ambiguity; choose a proportionate plan; implement and run
the checks.
Stop: [deadline, bounded retries or blocked prerequisite]. Return changed files, executed checks and unresolved
risks.
Use only fields that add information. For a tiny, clear change, a short request plus an exact file and verification
step may be enough. Do not force planning or lengthy explanations on every edit.
Agent interviews the developer
Before implementing, interview me about the uncertainties that could change the design or acceptance criteria. Ask
one high-impact question at a time, at most five. Offer a recommended default and explain its consequence. Then
summarize the decisions and remaining assumptions. Resolve or defer any consequential uncertainty still open after
the five-question training limit.
Agent challenges the design
Review this proposal for fragile assumptions and avoidable complexity. Identify the strongest simpler alternative,
likely failure modes and one cheap experiment that could change our choice. Tie each concern to a concrete
consequence; stop after the material issues.
Developer checks the agent
What evidence supports completion? List the commands actually executed, the relevant outputs and any untested
behavior. Which check would fail if your implementation were wrong? Identify one assumption I should
independently verify.
A worker contract
Task and input: [one bounded deliverable and source revision].
Ownership: [allowed files or read-only scope]. Dependencies: [required artifact].
Return: changed files or commit, checks executed, output artifact and open assumptions.
Do not claim completion without the required evidence. Stop after [bound] and return a reproducible blocker if
needed.
